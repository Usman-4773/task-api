# Task API

A simple CRUD API built with Python and FastAPI.

This project was created for the BE-01 Backend AI Engineering Week 2 assignment.

## Features

- Create tasks
- Read all tasks
- Read a single task
- Update tasks
- Delete tasks
- Input validation
- Correct HTTP status codes
- Interactive Swagger UI
- In-memory task storage

## Requirements

- Python 3.10+
- FastAPI
- Uvicorn
